03 · RAG WORKFLOW

合同智能
审查系统

以文本解析、知识图谱与 RAG 为基础，为合同和规章提供可追溯的初审与风险提示，连接文件理解、检索证据与审查结论。

RAGLightRAGKnowledge GraphMCP

PROBLEM

审查信息分散，
证据难追溯

合同条款、规章制度与外部法规分布于不同文档；人工初审耗时，且难以快速定位审查结论对应的依据。

METHOD

解析、图谱、检索
协同工作

通过文本解析构建实体关系，结合 PMI 与 LightRAG 构建知识检索链路；以 Plan-and-Execute + MCP 编排审查过程，并以 DOM 行级锚点回链原文。

RESULT

形成可解释的
初审闭环

内部检索效果提升 32%，合同或规章初审可在 5–10 分钟内完成，法律人员采纳率达到 90%。

WORKFLOW IN PRODUCT

把多个步骤组织成审查闭环

六张界面都来自同一系统链路，按“文件进入 — 审查执行 — 结果回看”的顺序组成连续界面组，而非拆散罗列。

TECHNOLOGY

技术栈

服务与前端Java 17 · Spring Boot · Vue 2 · Element UI · SSE

智能检索LangChain4j · LightRAG · 知识图谱 · RAG

数据与部署MySQL · Redis · Milvus · Neo4j · Docker
