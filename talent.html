04 · DATA INTELLIGENCE

AI 智能
人才引擎

将自然语言问题转化为可验证的数据库查询，让业务人员无需编写 SQL 即可获得人才数据洞察。

Text-to-SQLSQL ValidationLLMData Analytics

PROBLEM

业务要数据，
但不应被 SQL 阻隔

人才分析问题往往由非技术人员提出；自然语言直接生成 SQL 容易遇到字段误用、过滤不完整或结果不可控的问题。

METHOD

自然语言理解 +
SQL 校验

设计 Text-to-SQL 链路，从问题识别、字段映射、语句生成到执行前校验逐层收敛，并以对话界面承接查询与解释。

RESULT

把人才数据查询
变成自然对话

在项目评测中，DeepSeek-V3 达到 100% 准确率，Qwen3-235B 达到 90%，Qwen3-32B 达到 80%。

QUESTION TO QUERY

一个问题，两段相连的体验

对话提问和结构化查询结果属于同一次数据分析链路，因此采用并列的大画面，让面试官快速看清“问什么、怎么查、得到什么”。

TECHNOLOGY

技术栈

核心能力Text-to-SQL · LLM · SQL Validation · Prompt Engineering

交互形态自然语言对话 · 结果解释 · 数据可视化

模型评测DeepSeek-V3 · Qwen3-32B · Qwen3-235B
